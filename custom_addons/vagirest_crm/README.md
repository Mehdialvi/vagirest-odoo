# VAGIREST CRM

Independent CRM module for Daneshpad Alavi / VAGIREST.

Planned scope:

- One central VAGIREST Sales team
- Shared CRM pipeline
- Customer commercial classification
- Product interests
- Lead source, sales channel and referrer
- Mobile-friendly visit forms
- Sales missions
- Controlled sales access
- Historical sales integration in a separate module

This module must not modify production, QC or direct stock workflows.
